## What is gathered.tools?
gathered.tools is a personal project I created to catalog and share the various tools I use in my work. Read more in this [blog post](https://nickfigner.com/projects/gathered-tools/).

## Can I create a feed?
Yes! You can read the [docs](https://gathered.tools/docs/) or use the brand new [feed creator](https://gathered.tools/devtools/generator/).

Did you create a cool feed? Submit it [here](https://forms.gle/y5YZsGrcsmfYD4J4A) and be featured in a future update of gathered.tools!
